== zod, strategy incremental
  ok   --cache, cold
  ok   --cache, warm
  ok   --cache --pipeline=full, cold
  ok   --cache --pipeline=full, warm
  ok   watching: the entry edited
  ok   watching: a module edited
  ok   watching: a file added beside the entry and imported
  ok   watching: a package.json edited
  ok   watching: a name made an export
  ok   edit 1 (the entry edited) changes the output
  ok   edit 2 (a module edited) changes the output
  ok   edit 3 (a file added beside the entry and imported) changes the output
  ok   edit 4 (a package.json edited) changes the output
  ok   edit 5 (a name made an export) changes the output
  ok   --cache after the edits
  ok   --cache after the edits undone
